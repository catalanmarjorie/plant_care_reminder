# Plant Care Reminder

A simple mobile app to help users remember when to water their plants.

[Click here to try my live app](https://2ee381cf1a1246ceb64b1b8aa37ca4fa-share.flutterflow.cloud/s/2ee381cf1a1246ceb64b1b8aa37ca4fa?key=tIXz_1JN7gHIQSgkkhlujc_MJYfSkuc-Ln3wZWFZIVg)

[Click here to watch my video demo](https://drive.google.com/file/d/1DYuA4beG2iafI_ShGXHIwrPhJg-fs6u2/view?usp=drivesdk)

# Features:
- Add new plant with name 
- Set watering schedule (daily, weekly)
- Notification reminder
- Mark as watered
- View plant list
