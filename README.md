# Plant Care Reminder

A simple mobile app to help users remember when to water their plants.

Features:
- Add new plant with name 
- Set watering schedule (daily, weekly)
- Notification reminder
- Mark as watered
- View plant list

How to Install and Run:
1. Clone this repository
2. Open in FlutterFlow / Flutter
3. Run `flutter pub get`
4. Run `flutter run`
